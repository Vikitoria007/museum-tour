# 🏛 Museum Tour — Виртуальный тур по музею (Интерактивное ПО для киосков)

**Коммерческий проект.** Приложение успешно прошло приёмку, официальный контракт подписан. ПО развернуто и функционирует на двух физических сенсорных терминалах непосредственно в залах музея.

Интерактивный виртуальный тур с панорамами 360°, навигацией между залами и информацией об экспонатах, работающий в режиме 24/7 (Kiosk Mode).

## 🚀 Что реализовано и работает

* **5 панорам 360°** — сцены залов музея.
* **Навигация между сценами** — бесшовные переходы между точками обзора.
* **Интерактивные экспонаты** — хотспоты с открытием боковой панели с описанием.
* **Оптимизация для терминалов:** Адаптация под сенсорные экраны и локальное кэширование для стабильной автономной работы.

## 🧰 Технологический стек

* **Client-Side Логика:** JavaScript, библиотека **Pannellum**.
* **Спецификация данных:** Структурированные конфигурационные объекты для связей между залами и контента.
* **Интерфейс:** HTML5, CSS3.
* **Контроль версий:** Git.

## 🎮 Как это работает в Production

Система запускается в полноэкранном режиме киоска, подгружает панорамы и использует конфиги для масштабирования и управления контентом.

## 🚀 Как запустить локально для разработки

1. Склонируйте репозиторий: `git clone https://github.com`
2. Запустите локальный веб-сервер для обхода CORS-политики браузеров.
3. Откройте в браузере `http://localhost:8000/panorama.html`.

# 🏛️ Museum Tour — Виртуальный тур по музею
> 🏛️ **Реальный заказчик.** Проект разрабатывается по заказу музея. 
> Ведутся переговоры о внедрении. Стоимость проекта обсуждается.

Интерактивный виртуальный тур по музею с панорамами 360°, навигацией между залами и информацией об экспонатах.

## 🚀 Что умеет

- **5 панорам 360°** — залы музея, снятые и склеенные вручную
- **Навигация между сценами** — переходы между точками обзора через панель управления
- **Интерактивные экспонаты** — кликабельные точки на панораме, которые открывают боковую панель с описанием
- **Стилизованные хотспоты** — кастомные точки с буквой «i»
- **Адаптивный интерфейс** — панель навигации с подсказками и плавными переходами

## 🧰 Технологии

| Технология | Назначение |
|------------|------------|
| Python | Склейка панорам, обработка изображений |
| HTML/CSS/JS | Интерфейс и логика тура |
| Pannellum | Библиотека для панорам 360° |
| Git | Контроль версий |

## 📂 Структура проекта

- `panorama.html` — основной файл тура
- `perfect_panorama4.jpg` … `perfect_panorama18.jpg` — панорамы залов
- `images/` — изображения экспонатов
- `pannellum.js`, `pannellum.css` — библиотека Pannellum

## 🎮 Как это работает

1. Пользователь открывает тур → загружается первая панорама.
2. Внизу — панель навигации с кнопками для перехода между залами.
3. На панораме видны стилизованные точки — это экспонаты.
4. При клике открывается боковая панель с названием и описанием экспоната.
5. Переходы между залами сопровождаются плавной анимацией.

## 🚀 Как запустить

1. Склонируй репозиторий:
```bash
git clone https://github.com/Vikitoria007/museum-tour.git
```
2. Открой panorama.html через Live Server или локальный сервер:
```bash
python3 -m http.server 8000
```
3. Перейди в браузере:
```text
http://localhost:8000/panorama.html
```
